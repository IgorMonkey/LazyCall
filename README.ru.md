# LazyCall

[![CI](https://github.com/IgorMonkey/LazyCall/actions/workflows/ci.yml/badge.svg)](https://github.com/IgorMonkey/LazyCall/actions/workflows/ci.yml)

**Нейрослоп для нейрослопа.**

Код сгенерировал. Теперь объясняй.

Сделано в Codex, чтобы помогать объяснять проекты, сделанные в Codex.

LazyCall помогает восстановить контекст проекта, собранного с AI, во время технического созвона: слушает разговор, сверяется с выбранными актуальными файлами и предлагает формулировку ответа, которую можно проверить.

[English](README.md) · [Скриншоты](docs/SCREENSHOTS.ru.md) · [Как помочь](CONTRIBUTING.ru.md) · [Приватность](docs/PRIVACY.ru.md) · [Планы](docs/ROADMAP.ru.md)

> **Экспериментальная альфа для Windows x64.** Приложение ещё сырое: возможны баги, задержки и неудачные подсказки. Тестируйте, приносите воспроизводимые ошибки и присылайте PR — проект открыт для участия.

## Что умеет

- Расшифровывает микрофон и системный звук локально через Whisper, на CPU или NVIDIA CUDA.
- Предлагает короткие ответы, привязанные к конкретной реплике собеседника, и поддерживает дополнительные вопросы в чате.
- Позволяет необязательно подключить папку репозитория, цель встречи и документы.
- Хранит редактируемую расшифровку, заметки, историю и итоги с основаниями.
- Даёт компактное окно поверх созвона, горячие клавиши, светлую и тёмную темы.

Для записи и расшифровки не нужны ни папка проекта, ни AI-провайдер. AI-ответы могут ошибаться: проверяйте технические утверждения и решения. Скорость зависит от модели, компьютера и необходимости читать код.

## Первый созвон

1. Выберите микрофон и окно созвона. Системный звук может включать другие приложения на том же устройстве вывода.
2. При желании подключите папку проекта через «Экран и файлы». Помощник получает ограниченный доступ только на чтение и не меняет код.
3. Начните встречу. Для AI-подсказок подключите Codex в настройках.
4. Нажмите «Подсказать ответ» или напишите свой вопрос. LazyCall показывает, к какой реплике относится ответ.
5. Завершите запись, проверьте итоги, сохраните или экспортируйте их, затем при необходимости продолжите работу в Codex.

В меню **«Ещё»** находятся **«Мини-окно»**, **«Экспорт»** и **«Как пользоваться»**. `Ctrl+Alt+Space` показывает или скрывает мини-окно. `Ctrl+Alt+Enter` запрашивает ответ во время записи. `Enter` отправляет вопрос, `Shift+Enter` добавляет строку; это меняется в настройках. Системное сочетание может быть занято другой программой — LazyCall покажет статус.

## AI-провайдеры

**Пока реализован только Codex.** LazyCall находит установленный нативный Codex CLI и позволяет подключить его через интерфейс. Если он не найден, можно открыть официальную инструкцию или выбрать `codex.exe`. Профиль LazyCall изолирован, поэтому может потребоваться отдельный вход.

Claude Code, прямые API OpenAI и Anthropic, OpenRouter, другие OpenAI-compatible сервисы и Ollama — направления для будущих адаптеров, а не доступные возможности. Контекст для участия — в [планах](docs/ROADMAP.ru.md). Изображения, веб-поиск, streaming и инструменты репозитория нужно проверять отдельно для каждого провайдера.

## Данные и приватность

Расшифровка выполняется на компьютере. Встречи, заметки, кадры выбранного окна и настройки остаются в legacy-папке совместимости `%APPDATA%\CallMe`: её имя сохранено, чтобы не потерять существующие данные. При использовании облачного помощника LazyCall передаёт ему нужные фрагменты встречи, материалов и кода; при включённом контексте экрана — кадр выбранного окна. Это не полностью офлайн-AI. До работы с чувствительными данными прочитайте [приватность и потоки данных](docs/PRIVACY.ru.md).

Записывайте разговоры с необходимым согласием участников. Не публикуйте реальные записи, фрагменты расшифровки, скриншоты, токены или закрытый исходный код в Issues.

## Запуск из исходников

Для разработки нужны **Windows x64**, **Node.js 24 LTS** и npm.

```powershell
npm ci
npm run build
npm test
```

`npm run setup` загружает закреплённые runtime и речевую модель для разработки. Сборка приложения, онлайн-установщик и проверки описаны в [инструкции сборки](docs/BUILD.ru.md).

## Статус и ограничения

Это ранний открытый проект, который ещё обкатывается на реальных созвонах. Подсказка может опоздать, неверно понять вопрос или дать ошибочный ответ. Интерфейс и поведение будут меняться по мере тестирования. Перед важной встречей проверьте звук и помощника на короткой тестовой записи.

- Поддерживается Windows x64; macOS и Linux не проверены.
- Удалённые собеседники пока не разделяются по именам, промежуточной расшифровки нет.
- Облачные подсказки требуют доступного провайдера и используют его лимиты.
- Первый поиск по незнакомому репозиторию может быть медленнее повторного.
- Интерфейс доступен на русском и английском; есть светлая, тёмная и системная темы.
- Проверка онлайн-установщика ещё не завершена. Конфигурация alpha-обновлений есть локально, но update feed ещё не опубликован.
