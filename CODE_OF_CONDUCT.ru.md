# Правила сообщества

[English](CODE_OF_CONDUCT.md)

Общайтесь уважительно и конструктивно. Мы рады участникам с любым опытом, бэкграундом и инструментами-помощниками. Обсуждайте код и наблюдаемое поведение; не оскорбляйте, не преследуйте людей и не публикуйте приватную информацию.

Используйте Issues и pull request для задач LazyCall. Подкрепляйте разногласия фактами; границы задачи и решения ревью определяют мейнтейнеры.

О проблемном публичном контенте сообщайте через инструменты GitHub. Для безопасности и приватности следуйте [SECURITY.ru.md](SECURITY.ru.md) и не публикуйте чувствительные детали. Мейнтейнеры могут модерировать комментарии или ограничивать участие, чтобы проект оставался безопасным и полезным.
