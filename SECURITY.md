# Security reporting

[Русский](SECURITY.ru.md)

Do not publish credentials, private transcripts, repository contents, or a working exploit involving someone else's data in a public issue.

Use **Security → Report a vulnerability** in the repository to report privately. If that option is unavailable, open only a minimal issue asking for a private contact route, with no secret, personal data, exploit details or proof of concept.

For a private report, include the affected version, Windows version, prerequisites, synthetic reproduction steps, observed impact, and any suggested mitigation. Do not scan systems you do not own or have permission to test.

LazyCall is an early preview. There is no supported older release line, response SLA, or bug bounty. Updates do not replace reviewing AI output or controlling which project and meeting data you share with a provider.
