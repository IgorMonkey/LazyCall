# Направления развития

[English](ROADMAP.md)

Этот список описывает намерения, а не доступные возможности или сроки выпуска.

## Текущий фокус

- Надёжный сценарий технического созвона: привязка ответа к вопросу, актуальное чтение кода, готовая формулировка ответа и честные сообщения об отсутствии данных.
- Скорость первого полезного ответа и устойчивость на длинных встречах.
- Понятная установка, подключение Codex, локализация и проверяемые релизы.

## Адаптеры помощника

| Направление | Состояние | Что важно проверить |
| --- | --- | --- |
| Codex app-server | Реализован | Версия CLI, поток событий, отмена, доступ к модели и чтение проекта. |
| Установленный Codex CLI | Реализован | Автообнаружение, выбор native EXE, изолированный профиль LazyCall. |
| Claude Code | Планируется | Официальный программный интерфейс, условия использования, инструменты и отмена. |
| OpenAI API | Планируется | Личный API-ключ, отдельный биллинг, модели и поддерживаемые возможности. |
| Anthropic API | Планируется | Личный API-ключ, потоковые ответы, изображения и вызовы инструментов. |
| OpenRouter / OpenAI-compatible | Планируется | Base URL, модели, возможности и отличия протокола; совместимость не предполагается автоматически. |
| Ollama / локальные модели | Планируется | Фактическая скорость на устройстве, длина контекста, инструменты и изображения. |

Новый адаптер должен явно описывать возможности: текст, изображения, streaming, поиск, инструменты, отмена и выбор модели. UI не должен предлагать недоступные возможности. Контекст встречи и безопасное чтение проекта остаются общей частью LazyCall, а авторизация и протокол — ответственностью адаптера.

Ключи нельзя хранить в исходниках, URL или открытом виде в обычных настройках. Реализация API-адаптеров должна сначала определить защищённое хранилище Windows, удаление ключа и тесты отсутствия секретов в логах. Нельзя заимствовать токены из других приложений без поддерживаемого механизма и действия пользователя.
