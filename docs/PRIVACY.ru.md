# Данные и приватность

[English](PRIVACY.md)

LazyCall сохраняет встречи и обрабатывает речь на компьютере. Это не означает, что облачный помощник работает офлайн или что все данные зашифрованы.

| Действие | Куда идут данные |
| --- | --- |
| Запись и распознавание | Микрофон и системный звук обрабатываются локальным Whisper; финальные реплики сохраняются локально. |
| Выбранный экран | Кадры выбранного окна сохраняются локально во время встречи; при включённом контексте экрана могут передаваться помощнику. |
| Обзор проекта и AI-вопрос | Нужные части расшифровки, заметок, документов и прочитанных файлов выбранного репозитория передаются настроенному облачному провайдеру. |
| Поиск в интернете | Включается для соответствующего запроса; применяется политика провайдера. |
| Экспорт / передача в Codex | По действию пользователя создаются локальные файлы или данные копируются в буфер; дальнейшая отправка зависит от целевого приложения. |
| MCP-интеграция | Включается отдельно; предоставляет клиенту ограниченный доступ на чтение сохранённых встреч и проектов. |
| Установка / обновления | Загружаются программные файлы из источников релиза и поставщиков; этот механизм не требует отправки текста встречи. |

Данные пользователя находятся в legacy-папке совместимости `%APPDATA%\CallMe`, включая встречи, заметки, выбранные кадры и отдельный профиль авторизации помощника. Имя папки сохранено, чтобы существующие данные не потерялись после переименования; удаление приложения сохраняет этот каталог. Не публикуйте его и не прикладывайте целиком к баг-репорту. Встроенного шифрования хранилища встреч нет; используйте защиту устройства и учётной записи Windows.

Папка проекта доступна помощнику через ограниченные инструменты чтения. Чувствительные и служебные имена, двоичные файлы и выход через ссылки запрещены; это не гарантирует, что в разрешённом текстовом файле нет конфиденциальных данных. Подключайте только материалы, которые вы вправе передать выбранному провайдеру. LazyCall не изменяет исходники проекта через эти инструменты.

У каждой AI-службы свои лимиты, правила обработки и хранения запросов. LazyCall не обещает за неё отсутствие хранения или обучения на данных. Расшифровка, заметки и история доступны без подключения облачного помощника.

Публичные скриншоты и тесты должны использовать синтетические данные. Сообщения об утечках передавайте по [SECURITY.ru.md](../SECURITY.ru.md).
