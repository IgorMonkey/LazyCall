# Пользовательский сценарий

Дата: 26 октября 2026. Этот документ описывает текущее приложение, а не план будущих версий.

## Начало без подготовки

CallMe можно использовать без проекта, цели, файлов и входа в Codex. Локальное распознавание использует поставляемые `whisper.cpp` и multilingual `large-v3-turbo-q5_0`; оно не требует сети. Проект, цель и материалы — дополнительный контекст, а Codex нужен только для ответов и итогов.

1. Выбрать окно и нажать «Начать встречу».
2. Читать итоговые реплики микрофона и системного звука с таймкодами. Заметки и цель можно добавлять до и во время разговора. «Пауза» приостанавливает оба потока и кадры; таймер и таймкоды остаются на общей шкале встречи, поэтому пауза видна как промежуток.
3. Быстрое действие ответа берёт последнюю видимую реплику собеседника и закрепляет её ID. Поздние реплики не меняют цель уже созданного запроса.
4. Нажать «Завершить». После настоящего окончания захвата приложение по умолчанию создаёт краткий итог, если Codex готов и есть реплики. Это можно выключить в настройках. Открытие истории не запускает генерацию.
5. Проверить содержание и черновые решения, задачи и открытые вопросы. Структурные AI-пункты содержат ID реальных реплик; пользователь меняет, подтверждает или отклоняет их. После остановки пользователь может исправить реплику: исходный вариант сохраняется, а краткий итог и пункты с этой репликой отмечаются как устаревшие до ручной проверки или обновления итога.

Пользователь сам говорит и отправляет сообщения. CallMe не присоединяется ботом к видеозвонку, не исполняет текст расшифровки или модели и не создаёт внешние задачи.

## Проект и материалы

Проект необязателен. В «Экран и файлы» доступно «Подключить папку» и без проекта: пользователь выбирает корень репозитория в системном диалоге. Список файлов и подтверждение каждого файла не нужны. Помощник ищет и читает нужные участки через три инструмента только на чтение. Изменения исходников видны при следующем чтении; общего лимита в 16 файлов нет.

Папка сохраняется отдельно для каждого проекта и для режима без проекта. При смене проекта прежняя папка не переносится в новый контекст. «Отключить папку» прекращает доступ для следующих запросов и удаляет её предварительный обзор. При готовом помощнике подключение автоматически запускает обзор; доступны остановка, правка и повторная подготовка.

Дополнительные документы — отдельные необязательные копии, до 16 файлов по 200 КБ, 1 МБ суммарно. Служебные деревья, ссылки, чувствительные имена и двоичные файлы исключены из чтения репозитория. Код не меняется, shell-команды недоступны. Работа без папки и входа сохраняется.

## Помощник и Codex

Для помощника нужен отдельный штатный вход Codex. Настройки получают каталог доступных моделей и уровней рассуждения из runtime, а пользователь явно выбирает допустимую пару. При пустом выборе runtime выбирает значение сам; текущая проверка по умолчанию показывает `gpt-5.6-sol`, но это не обещание фиксированной модели для каждого аккаунта или будущего runtime.

Помощник получает текст встречи, заметки, выбранные копии материалов, при включённой опции — свежий кадр выбранного окна, и нужный контекст проекта. Поиск включается отдельным действием пользователя. Локальный Whisper не отправляет аудио в Codex.

После записи доступна передача в Codex: новый черновик `codex://new` с `meeting.md`, `context.md` и справкой проекта либо копирование итогов для уже открытого чата. Новый чат не открывается автоматически после Stop. Отправку делает пользователь в Codex.

В передаче и настройках данных можно включить локальный CallMe MCP. Он read-only и ограничен списком проектов, списком встреч, чтением встречи и чтением проекта. Включение открывает страницу сгенерированного плагина; пользователь устанавливает её в Codex один раз. После выключения новые tool calls блокируются, а файлы плагина остаются. Приложение не читает и не меняет глобальный профиль или авторизацию Codex. Установка и обнаружение инструментов подтверждены bundled Codex в изолированном профиле, в том числе из packaged CallMe.exe. Установку в своём Codex пользователь завершает на странице плагина.

## Навигация и настройки

Расшифровка и панель помощника следуют за новыми элементами, пока пользователь находится внизу. Ручная прокрутка останавливает следование; кнопка «К последней …» или возвращение в конец его возобновляет. Переход от итога к реплике показывает её в расшифровке. Запрос, импорт материалов и генерация имеют видимые статусы.

Настройки разделены на запись, помощника, оформление и данные. В них находятся язык/вычисления и подсказки, модель/рассуждение/автоитоги/экранный контекст/Enter, системная/светлая/тёмная тема и путь к данным. Тема предварительно применяется сразу; отмена возвращает исходную, сохранение записывает выбор и обновляет native chrome.

## Что пока отсутствует

Нет partial-расшифровки, диаризации удалённых участников, автоматического определения говорящих, произвольного выбора output endpoint и облачных STT-провайдеров. Исправление сохранённой реплики доступно только после остановки и не меняет её исходный текст. Есть per-user офлайн-установщик. Нет автообновления, подписи, отдельной загрузки модели из интерфейса и подтверждённого запуска на другом компьютере.

## Основания решений интерфейса

Явные состояния и видимая реплика для ответа опираются на [NN/g: visibility of system status](https://www.nngroup.com/articles/visibility-system-status/) и [recognition rather than recall](https://www.nngroup.com/articles/recognition-and-recall/). [Granola описывает](https://help.granola.ai/article/ai-enhanced-notes) автоматическое создание заметок после остановки, проверку оснований и последующее редактирование. В CallMe эти принципы применены к своему сценарию; это не заявление о совместимости.

Документация [MCP](https://learn.chatgpt.com/docs/extend/mcp) и [плагинов](https://developers.openai.com/plugins/build/plugins) описывает используемую внешнюю платформу. Собственная проверка установки сохранена в `test-results/plugin-install.json`.
