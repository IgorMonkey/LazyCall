# Архив: локальная переносимая сборка Windows

> Историческая инструкция для разработчика. Для актуальной публичной поставки используйте [BUILD.ru.md](BUILD.ru.md); описанные здесь старые сборки с app-local VC DLL и Codex не публикуются.

Сборка предназначена для Windows x64. Запускать нужно `CallMe.exe` из всей папки
`release/win-unpacked`: рядом лежат Electron и встроенный Whisper. Копировать один
EXE недостаточно. Для распознавания на другом компьютере Python, CUDA Toolkit и
отдельный Whisper не нужны. Режим «Автоматически» использует NVIDIA, когда
нативный движок действительно загрузил CUDA; иначе работает CPU. Режим «Процессор»
можно выбрать в настройках.

## Подготовка разработчиком

```powershell
yarn install --immutable
yarn setup
yarn pack
```

## Обычный установщик

`yarn dist:win` собирает офлайн-установщик NSIS в
`release/compact-offline`. Это не web-installer и не механизм обновлений:
CPU/CUDA runtime Whisper, модель и лицензии находятся внутри пакета. Установщик
русскоязычный, пошаговый и по умолчанию устанавливает программу для текущего
пользователя в `%LOCALAPPDATA%\Programs\CallMe`; папку можно изменить. Он создаёт
ярлыки на рабочем столе и в меню «Пуск» и не запускает приложение после установки.

Удаление снимает программу и её ярлыки, но сохраняет `%APPDATA%\CallMe`, включая
встречи, настройки и вход. Установщик пока не подписан. Нет автообновлений и
загрузки модели из приложения.

Упаковка использует LZMA2, уровень 7, словарь 32 MiB и четыре потока. Ограничение
словаря и потоков предотвращает прежний чрезмерный расход памяти упаковщика;
состав приложения остаётся полным. Для перепаковки уже собранного приложения той
же версии без изменений файлов:

```powershell
node scripts/build-installer.cjs --prepackaged release/ui-spacing/win-unpacked
$env:CALLME_INSTALLER_PAYLOAD='1'
yarn test:installer
```

Перепаковка сверяет все исходные и выходные файлы по размеру и SHA256. Проверка
payload отдельно извлекает архив из готового EXE и повторно сверяет его со staging;
production-установщик при этом не запускается. Сжатие уменьшает размер скачивания,
а не место, которое занимает установленная программа.

27 октября 2026 версия 0.3.4 перепакована в
`release/compact-offline/CallMe Setup 0.3.4.exe`: 1 050 920 634 байта вместо
1 175 950 430 байт, экономия 125 029 796 байт (10,63%). Все 133 файла исходной
папки сохранены побайтно, содержимое готового EXE прошло сверку SHA256.
Установленная папка занимает прежние 2 645 113 399 байт. Packaged-проверка
подтвердила запуск приложения и распознавание синтетической речи через CUDA;
36 скомпилированных файлов совпали с исходной сборкой.
Отчёт: `test-results/final-compact-offline-release.json`.

`setup:whisper` загружает официальные CPU/CUDA runtime whisper.cpp v1.9.2,
cuBLAS 11.11.3.6 из redistributable NVIDIA и модель large-v3-turbo-q5_0. Затем
он проверяет SHA256 и подпись Microsoft закреплённого VC Redistributable, без
запуска установщика извлекает только четыре x64 DLL рядом с Whisper и проверяет
их подписи, архитектуру и хеши.
SHA256 архивов и модели записаны в `runtime/whisper/manifest.json`; архив NVIDIA
проверяется по закреплённому SHA256, модель — по опубликованному SHA1. Архивы ZIP
и незавершённые загрузки не входят в сборку. Текущие распакованные ресурсы Whisper
занимают около 1,84 GB; исходные ZIP нужны только для повторной сборки.

Лицензии Whisper, модели, cuBLAS, Microsoft VC Runtime и шрифта поставляются с приложением. После
обновления версии runtime или модели нужно повторно проверить состав сборки.
Текст Microsoft VC Runtime сохранён как доказательство источника и условий, но
сам по себе не предоставляет право разработчику распространять DLL: перед
публичной поставкой требуются применимые права Visual Studio и соответствующий
REDIST-лист.
`setup:codex` включает в переносимую папку Codex CLI 0.145.0 с его лицензией.
На новом компьютере вход через ChatGPT выполняется в самом CallMe; приложение
использует собственный каталог авторизации и не переносит чужие токены.

## Воспроизводимые проверки движка

```powershell
node scripts/create-speech-fixture.cjs
yarn build
node scripts/check-runtime.cjs
node scripts/smoke-desktop.cjs
node scripts/check-settings.cjs
node scripts/check-ui.cjs
yarn pack
node scripts/check-packaged.cjs
yarn dist:win
yarn test:installer
yarn test
```

Генератор WAV использует установленный русский системный голос Microsoft Irina
и пишет речь только в файл. Проверки не включают реальный микрофон: runtime test
передаёт синтетический WAV напрямую, UI test запускается с fake media devices.
Окно для проверки кадров создаётся самим тестом. Закрываются только процессы и
окна приложения, созданные тестом.

`check-runtime.cjs` проверяет распознавание обеих сторон, сохранение финалов при
остановке, настоящий CPU fallback через отдельный manifest, честное отображение
CPU при молчаливом отказе от GPU, остановку собственного процесса и отмену
загрузки без последующего повторного запуска. Основной runtime не изменяется.
Результат записывается в `test-results/runtime-check.json`.

На RTX 2080 Ti синтетическая фраза длительностью около девяти секунд обрабатывалась
за 0,25–0,37 с после загрузки модели; на CPU — примерно за 10 с. Это локальный
регрессионный замер, не гарантия задержки на другом компьютере или живой речи.

## Перед передачей сборки

26 октября 2026 сборка 0.3.1 с прямым подключением репозитория сохранена в
`release/repository-context`. Установщик — 1 053 749 120 байт. Проверены
подключение папки без проекта/входа в packaged-приложении, чтение через нативный
fixture, свежесть после правки, изоляция проектов и отключение после перезапуска.
Настоящий bundled app-server принял dynamic tool schema в отдельном пустом
профиле; облачный turn в этой проверке не запускался. Все 33 compiled-файла
совпали с `app.asar`; unit tests: 52 passed, 2 skipped из-за прав на file symlink,
при этом directory-junction escape проверен. Полный отчёт —
`test-results/final-repository-context-release.json`.

Проверить запуск именно `release/win-unpacked/CallMe.exe` с отдельным каталогом
пользовательских данных, готовность встроенной модели и распознавание fixture.
Проверить отсутствие обращения к исходной папке проекта для Whisper и шрифтов.
Для проверки на втором компьютере перенести всю папку, запустить CPU режим,
выбрать микрофон и окно, завершить короткую встречу и открыть экспорт Markdown.
Реальные Zoom/Телемост, акустическое эхо и нагрузку длительной встречи нужно
проверять отдельно от синтетических тестов.

25 октября 2026 упаковка и `check-packaged.cjs` прошли на текущем компьютере.
Распакованная папка занимает 2 657 725 597 байт (около 2,66 GB), включая CPU/CUDA
Whisper, модель и Codex. Проверка подтвердила отдельный userData через
`--user-data-dir`, настоящее распознавание из встроенных ресурсов, готовый вход
через ChatGPT в свежем профиле, шрифты/иконку/лицензии и экспорт Markdown.
Сборка пока не подписана сертификатом разработчика.

26 октября 2026 собран `release/compact-installer/CallMe Setup 0.3.0.exe`:
1 036 587 669 байт (около 1,04 GB); установленная папка — 2 645 066 564 байта
(около 2,65 GB). Packaged-проверка подтвердила настоящее распознавание,
отдельный профиль, шрифты, темы, импорт папки, экспорт, передачу в Codex и
ограниченный API мини-окна. Проверка движка отдельно подтвердила загрузку всех
четырёх VC DLL из локальных папок CPU и CUDA. Все 32 скомпилированных файла
совпали с содержимым `app.asar`. Отдельный вариант установщика с уникальными
именем, EXE и GUID прошёл установку и удаление; его каталог и запись реестра
удалены. Production-установщик тестом не запускался. Автообновлений нет.

`check-installer.cjs` по умолчанию проверяет изолированный staging-вывод
установщика: текущую версию приложения, состав bundled Whisper и настройки NSIS.
Реальная установка production-артефакта не запускается тестом. Для отдельной
механической проверки есть opt-in `CALLME_INSTALLER_ISOLATED=1`: он собирает в
временную папку вариант с уникальными appId, GUID, названием продукта и EXE,
устанавливает его только в собственную временную папку и удаляет. Этот вариант не
совпадает с обычным CallMe в реестре, ярлыках, данных или поиске процессов.
