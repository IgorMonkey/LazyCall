# Компоновка интерфейса

[English](UI_GUIDELINES.md)

В LazyCall графитовая палитра с коралловым акцентом для действий. Русская и
английская версии используют одну сетку, типографику и размеры элементов;
переведённый текст может переноситься.

- Связанные элементы располагаем рядом: 8px внутри небольшой группы, 16px между
  связанными группами, 24px для обычных отступов содержимого диалогов. В компактной
  компоновке отступы уменьшаются, порядок чтения сохраняется.
- Основные панели делят строки сетки: заголовки, истории, подписи полей, поля и
  действия. Истории прокручиваются независимо. Длинный ответ, кнопка перехода к
  последнему сообщению и уведомление о подключении не сдвигают поля ввода.
- Заголовок и нижние действия диалога остаются видимыми при прокрутке содержимого.
  Не вкладываем диалоги друг в друга и не показываем модальное окно ради статуса.
- Сохраняем видимый фокус клавиатуры, понятные подписи и выделение текста.
  Для публичных скриншотов используем вымышленные данные.

Это решения проекта на основе рекомендаций [Fluent по компоновке](https://fluent2.microsoft.design/layout),
[Fluent по диалогам](https://fluent2.microsoft.design/components/web/react/core/dialog/usage),
а также NN/g о [близости элементов](https://www.nngroup.com/articles/gestalt-proximity/)
и [визуальной согласованности](https://www.nngroup.com/articles/why-does-design-look-good/).
Они не означают формальную сертификацию и не заменяют проверку с пользователями.

`node scripts/check-assistant-ui.cjs --spacing` проверяет геометрию элементов и
основных панелей, `--workspace-review` снимает адаптивные состояния, а
`--transcript-follow` проверяет прокрутку. Галерея также охватывает настройки,
материалы, проекты, итоги, онбординг и мини-окно.
