# Как помочь LazyCall

[English](CONTRIBUTING.md)

Нужны исправления, улучшения UX, переводы, тесты, документация и адаптеры AI-провайдеров. Для большой функции сначала откройте Issue, чтобы обсудить границы и пользовательский сценарий. Небольшие точечные исправления можно присылать сразу pull request.

## Разработка

Используйте Windows x64, Node.js 24 LTS и npm.

```powershell
npm ci
npm run build
npm test
```

Эти проверки не должны использовать аккаунт ChatGPT, реальные данные встреч, микрофон, запросы к моделям или облачные сервисы. `npm run setup` загружает нативные зависимости для разработки; перед упаковкой нативных бинарников прочитайте [инструкцию сборки](docs/BUILD.ru.md).

## Pull request

Опишите проблему пользователя, итоговое поведение и проверку. В скриншотах используйте синтетические разговоры и названия проектов. Запустите команды выше и профильные проверки; не заявляйте проверки, которые не запускали.

Помощь AI допустима, но автор должен понимать и уметь объяснить изменение. Не смешивайте исправление с несвязанным рефакторингом. Сохраняйте совместимость с сохранёнными встречами и настройками. Автотесты не должны запускать реальный микрофон, отправлять запросы модели или создавать внешние чаты без явного opt-in.

Не коммитьте `runtime/`, `release/`, `test-results/`, файлы авторизации, приватные расшифровки, API-ключи или скриншоты с персональными данными. Перед коммитом проверьте staged-файлы.

## Адаптеры провайдеров

Сейчас реализован только Codex. Claude Code, API OpenAI и Anthropic, OpenRouter, другие OpenAI-compatible сервисы и Ollama — планы; см. [roadmap](docs/ROADMAP.ru.md). Новому адаптеру нужны проверки streaming, отмены, ошибок и таймаутов, изолированных учётных данных, доступа к проекту только на чтение и недоступных возможностей. Нельзя молча переключать провайдера или брать токены другого приложения.

## Где искать задачи

Для небольших задач используем метку `good first issue`, а для направлений, где нужна помощь сообщества, — `help wanted`. Также полезны идеи, баг-репорты и улучшения документации.
