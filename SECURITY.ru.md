# Сообщения об уязвимостях

[English](SECURITY.md)

Не публикуйте в публичном Issue учётные данные, приватные расшифровки, содержимое репозитория или рабочий эксплойт с чужими данными.

Для приватного сообщения используйте **Security → Report a vulnerability** в репозитории. Если такой кнопки нет, создайте только короткий Issue с запросом приватного канала — без секретов, персональных данных, деталей эксплойта и proof of concept.

В приватном сообщении укажите затронутую версию, Windows, предусловия, шаги воспроизведения на синтетических данных, наблюдаемый эффект и возможное исправление. Не сканируйте системы, которые вам не принадлежат или на проверку которых у вас нет разрешения.

LazyCall — ранняя версия. Нет поддерживаемых старых веток, SLA ответа или bug bounty. Обновления не заменяют проверку AI-ответов и контроль данных проекта и встречи, передаваемых провайдеру.
